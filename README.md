# BaitCheck

Adaptive Social Engineering Training Platform.
Built with the MERN stack and Google Gemini AI.

## Project Structure
- `/client`: React + Vite frontend
- `/server`: Node.js + Express backend
- `/server/ai`: Gemini AI engine, safety filters, and scoring logic
- `/server/scenarios`: JSON scenario definitions

## Setup
1. Copy `.env.example` to `.env` and fill in your keys.
2. Refer to `CONTEXT.md` for the shared API contract and architecture.
